ฝึกพิมพ์คำสั่ง ภาษา Python ด้วยตนเองและดูผลลัพธ์จริง!

เกมเพื่อการศึกษาสำหรับนักเรียน ชั้นมัธยมศึกษาปีที่ 3 เน้นปูพื้นฐานให้เข้าใจง่าย เลือกฝึกได้ทั้งคำสั่งแสดงผล print() คำสั่งรับข้อมูล input() และ ตัวแปรพื้นฐาน โดยให้นักเรียนได้ลองพิมพ์โค้ดจริงและโต้ตอบกับหน้าจอ Terminal ทันที!

hello_m3.py
# ตัวอย่างคำสั่งพื้นฐานที่เข้าใจง่าย
name = input("พิมพ์ชื่อของคุณ: ")
print("สวัสดี", name)
ผลลัพธ์เมื่อกดรัน (Terminal):
> พิมพ์ชื่อของคุณ: น้ำใส
> สวัสดี น้ำใส

1. ลองพิมพ์คำสั่ง Python ด้วยตนเอง

อ่านโจทย์ภารกิจ แล้วพิมพ์คำสั่ง print(), input() หรือสร้าง ตัวแปร ลงในพื้นที่เขียนโค้ด (สามารถกดปุ่มช่วยพิมพ์ด้านบนช่องโค้ดเพื่อความสะดวกได้)

2. กดรันโปรแกรมและโต้ตอบกับ Terminal

เมื่อพิมพ์โค้ดเสร็จ ให้กดปุ่ม "▶ รันคำสั่ง" หากในโค้ดมีคำสั่ง input() หน้าจอ Terminal จะหยุดรอให้คุณพิมพ์ข้อมูลตอบโต้จริงและกด Enter

❤️

3. พลังชีวิตและการให้คะแนน
